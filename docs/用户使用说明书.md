## 一、开始使用

### 1. 登录 / 注册

- 打开型刻后进入登录页，首次使用请点击上方 **「注册」** 标签。
- **用户名**：3~32 位，支持字母、数字、下划线、中文。
- **密码**：至少 6 位。
- **昵称**（可选）：别人看到的名字，不填则默认同用户名。
- 注册成功后自动登录并进入主页。

### 2. 界面总览

登录后的界面分三块：

| 区域 | 说明 |
| --- | --- |
| **左侧导航** | 在 7 个功能页之间切换；点最下方的箭头可折叠/展开侧边栏 |
| **顶部栏** | 显示当前页面标题；右上角有头像菜单（点击可 **退出登录**） |
| **主内容区** | 当前页面的功能内容 |

## 二、AI 对话（核心页）

这是型刻的心脏。所有健康数据都可以在这里"用说话的方式"记录，AI 会自动整理并归档。

### 1. 直接开聊

在底部输入框打字，按 **Enter** 发送（Ctrl+Enter 可换行）。正在生成时，发送按钮会变成 **停止按钮（■）**，可随时中断。

**推荐的开聊方式**：

- 「我今天吃了一个苹果和一杯牛奶」→ AI 回复后会自动弹出**饮食确认卡**
- 「刚喝了 300ml 水」→ 自动弹出**饮水确认卡**
- 「请帮我记录今日体重：75.2kg」→ 记录体重并给出趋势反馈
- 「我今天该练什么？」→ 结合你的身体数据给运动建议
- 「来一份 1600 千卡的减脂食谱」→ 生成专属食谱卡片

### 2. 拍照记饮食

- 点击输入框上方的 **「📷 记饮食」**，或直接把食物照片**拖拽**到输入框。
- AI 视觉模型会识别图中的食物和分量，识别结果以卡片形式展示。

### 3. 饮食 / 饮水确认卡（重要！）

当 AI 识别到你报告了饮食或饮水时，回复下方会出现确认卡：

- 卡片显示识别到的食物清单、克数、热量和三大营养素（蛋白 P / 碳水 C / 脂肪 F）。
- 点 **「✓ 计入今日热量」/「✓ 计入今日饮水」** → 记录正式入库，右侧统计卡立即更新。
- 点 **「不计入」** → 放弃本次识别，不影响任何数据。
- **未处理的卡片刷新页面后依然保留**，随时回来确认。

### 4. 四个快捷按钮

输入框上方一排快捷入口：

| 按钮 | 作用 |
| --- | --- |
| **记饮食** | 打开相机/相册，拍照识别食物 |
| **记体重** | 弹窗输入体重（kg），AI 会结合趋势给出反馈 |
| **今日计划** | 让 AI 直接生成今日饮食 + 运动总览 |
| **生成食谱** | 弹窗选择「当日食谱（3 餐）」或「本周食谱（21 餐）」，按你的身体数据定制 |

### 5. 右侧信息栏（可自定义）

对话区右侧默认展示 6 张实时卡片：

1. **今日热量**：摄入/预算/剩余 + 蛋白质、碳水、脂肪进度条
2. **今日饮水**：动态水杯水位动画 + 各类饮品构成
3. **运动计划**：今日计划与完成打卡（详见下文）
4. **运动热量消耗**：已完成项目消耗汇总
5. **热量缺口**：摄入 vs（基础代谢 + 运动消耗）
6. **目标进度**：当前体重 → 目标体重

- 点 **「+ 添加卡片」** 可自由勾选显示哪些卡片（配置自动保存）。
- 信息栏右上角的按钮可整体收起/展开。
- 卡片上的数字很多**可以直接点铅笔图标 ✏️ 修改**：
  - 热量预算、饮水目标、今日已饮水量（用于手动补差）。

### 6. 右侧「运动计划」卡的用法

1. 选择运动类型：**有氧 / 力量 / 无氧**。
2. 从下拉框选择具体运动（括号内是强度系数 MET，越大越累）。
3. 拖动滑块设置时长（5~120 分钟），系统实时估算消耗。
4. 点 **「添加到计划」**。
5. 做完后点该项的 **「完成」** 并确认，消耗才会计入统计。
6. 常用组合可点 **「保存为模板」**，以后一键套用（如"减脂有氧日"）。

### 7. 历史对话与清空

- 顶栏 **日历图标 📅**：打开日历面板，点任意日期查看那天的对话（只读回顾）。
- 点 **「回到今天」** 返回当前会话继续聊。
- **「清空对话」**：删除当天全部会话记录（不可恢复，会二次确认）。
- 鼠标悬停 AI 消息：出现**复制 / 点赞 / 点踩 / 反馈**按钮。

## 三、饮食记录

集中查看和管理每一天吃了什么。

- **热量概览**：顶部圆环显示当日摄入百分比，含已摄入、热量预算、剩余可吃、三大营养素汇总。
- **自定义热量预算**：点「热量预算」旁的 ✏️，推荐范围——减脂期 1200-1600、维持期 1600-2000、增肌期 2000-2800 kcal；也可直接用系统按你的身体数据算出的 **TDEE 建议值**。
- **按日期翻阅**：右上角箭头前后翻一天，或点日期直接跳转（最多到今天）。
- **记录来源标记**：每条记录会标注来源——💬 对话上报 / 🛒 外卖下单 / 🧊 冰箱菜谱，并显示餐次（早/午/晚/加餐）。
- 灰色显示的记录表示「未计入统计」（下单时勾选了不计入）。

## 四、外卖选购

想吃外卖又怕热量超标？在这里点，热量自动入账。

1. **选店**：按品类筛选或直接浏览店家列表，点卡片进入店铺菜单。
2. **点餐**：选菜品，弹窗中设置：
   - 数量
   - 餐次（早餐/午餐/晚餐/加餐）
   - **是否计入今日热量统计**（默认计入；想吃顿"欺骗餐"就取消勾选）
3. **下单**：成功后 toast 提示已计入多少 kcal，左侧「今日订单」实时更新。
4. **取消订单**：在今日订单列表中点取消，热量同步扣回。
5. 顶部汇总条显示：今日订单数、外卖总热量、已计入统计的热量与蛋白质。
6. 店铺菜单页地址带 `?shop=店名`，刷新后仍停留在当前店铺。

## 五、我的冰箱

管理家里食材，AI 帮你想菜谱。

### 1. 入库食材

- **拍照入库**：调起相机拍一张，视觉 AI 自动识别食材和克数，识别结果以标签形式确认入库。
- **手动添加**：填写名称、分类、数量（g）、过期日期等。
- 食材卡片可随时 **编辑 ✏️ / 删除 🗑**（删除有二次确认）。

### 2. 库存总览

顶部一行显示：食材种类、分类数、总库存量、**已用完 / 预计过期 / 已过期** 数量——该补货、该先吃谁一目了然。
左侧分类导航含「预计过期」「已过期」快捷筛选。

### 3. AI 菜谱推荐

1. 在底部菜谱区选择口味偏好（如低脂、快手菜），或在输入框写想吃的菜名。
2. 点 **「根据冰箱推荐」**，AI 基于现有食材生成菜谱，含整餐营养估算和**哪些食材用冰箱里的**。
3. 做好饭后点菜谱上的 **「确认烹饪」**：
   - 这餐自动记入当日饮食；
   - 用到的食材从冰箱库存中**自动扣减**。

## 六、运动记录

独立的运动数据中心。

- **本周统计**：本周运动次数、总消耗、总时长。
- **运动统计图表**：可切换 **周 / 月 / 年** 视图，柱状图展示每日（或每月）消耗；鼠标悬停看明细；月/年视图可用箭头翻年份。
- **运动计划**：与 AI 对话页右侧的运动计划卡同源——选择运动类型、项目、时长后添加；点「完成」确认打卡；支持**保存/套用模板**（如"减脂有氧日"）。
- 运动消耗按 **MET × 体重 × 时长** 计算，确认完成的运动才计入。

## 七、活动（组局运动）

约上伙伴一起运动，还能在活动群里聊。

### 1. 发现与加入

- 活动列表可按**运动类型、城市**筛选，搜索框支持按活动名称/地点/描述搜索。
- 点活动卡片进入详情：查看时间地点、人数、参与者。
- 点 **「加入活动」**：立即成为成员并**自动进入活动群聊**；人满则显示"已满员"。
- 已加入的可**退出活动**。

### 2. 发起活动

点右上角 **「发起运动活动」**，填写：

| 字段 | 说明 |
| --- | --- |
| 活动名称 * | 如「周末朝阳公园篮球局」 |
| 运动类型 * | 篮球、跑步、羽毛球等 |
| 人数上限 * | 1~500 |
| 城市 * / 行政区 / 具体地点 | 方便伙伴找场 |
| 日期 * / 时间 | 活动开始时间 |
| 活动描述 | 安排、注意事项、装备要求 |

创建成功后**自动建立活动群聊**，你以管理员身份进入。

### 3. 活动群聊

详情页切换到 **「群聊」** 标签即可发言；加入活动时也会自动跳入群聊。

## 八、我的档案

你的身体数据中心与成长曲线。

- **核心指标卡**：当前体重、BMI（含胖瘦评级）、本周运动次数；体重和 BMI 卡可直接点开编辑，保存即入库。
- **体重趋势图**：
  - 维度切换：体重 / 体脂率 / 腰围 / 臀围。
  - 时间范围：周 / 月 / 年。
  - 图下方显示最高值、最低值、平均值、整体变化。
- **目标进度环**：当前体重 → 目标体重完成百分比（目标体重可在与 AI 对话中设置）。
- **综合统计**：日均摄入、运动次数、体重变化、饮食打卡率。
- 身高、目标体重等基础资料可在与 AI 的对话中补充，AI 会自动记录。

## 九、小技巧与常见问题

**Q1：饮食确认卡没弹出来？**
确认消息里带明确的「吃了/喝了」表述（如"我午饭吃了一碗米饭"）。识别通常在回复后几秒内弹出；若关闭了页面，刷新后卡片依然在。

**Q2：识别的食物/克数不对怎么办？**
直接点「不计入」放弃本次，再用更明确的表述重新说一遍（带数量更好），或用拍照识别。

**Q3：想改喝水目标 / 热量预算？**
AI 对话页右侧卡片的数字旁有 ✏️ 图标，点击直接改；饮食记录页也可改热量预算。

**Q4：喝了奶茶/咖啡算饮水吗？**
算。确认卡会自动区分水/茶/咖啡/果汁/牛奶/汤，右侧饮水卡会分类型统计（喝酒不计入）。

**Q5：手动补记今天的饮水总量？**
点右侧饮水卡「已摄入」旁的 ✏️ 直接设为实际值（大于当前值补差、设 0 清空重来）。

**Q6：热量统计里找不到某条外卖？**
下单时如果取消了「计入今日热量统计」，该订单在饮食记录中显示为灰色「未计入统计」。

**Q7：忘了记当天数据怎么办？**
饮食记录页可以翻到任意历史日期查看；但**新的记录只能记在当天**——饮水、运动同理，建议当天随手记录。

**Q8：怎么退出登录？**
右上角头像 → 退出登录。
